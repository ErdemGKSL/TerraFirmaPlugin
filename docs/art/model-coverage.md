## How to read the table

- **TFC entity model**: a concrete class in `client/model/entity/`, minus layers, block-entity models, a projectile model and base classes (listed under Excluded).
- **Species key**: the id our generator would use, `tools/models/species/tfp_<key>.json`.
- **Parameter file**: `yes` if `tools/models/species/tfp_<key>.json` exists.
- **Generated .bbmodel**: `yes` if `tools/models/out/tfp_<key>.bbmodel` is committed. `local only` if the file exists in the git-ignored `out/` folder (not reproducible from the repo without its inputs). `no` otherwise.
- **TFC animations**: AnimationDefinition constants in the entity model class and its `client/animation/<Name>Animation.java` file.
- **Our animations**: `0 of N` when no committed model exists. `unknown` for a local-only draft, because its source conversion cannot be verified from the repo.
- **Status**: `not started` (no parameter file, no output), `param only` (inputs, no committed output), `local draft` (output without committed inputs or output), `generated` (committed output).
