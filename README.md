# Cairnlands

A from-scratch reimplementation of the TerraFirmaCraft survival experience as a **Paper + Folia** plugin for **vanilla clients**. Visuals come from CraftEngine, BetterModel and BetterHud, which the plugin installs and configures. Licence: EUPL-1.2. Not affiliated with TerraFirmaCraft; attribution in `NOTICE`.

Status: in development (see `plans/parity/STATUS.md`). Product name decision: `docs/release/product-name.md`. Design: `PRD.md`, `ARCHITECTURE.md`.
